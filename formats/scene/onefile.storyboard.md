---
message: one JSON file becomes one video, and the same file always makes the same video
audience: people who build product videos by hand and re-do them every time a number changes
framework: BAB
object: the JSON card
duration: 15s
format: 1920x1080
---

## Beat 1: One file (0s-3.5s)
- onscreen: One file.
- narration: This is the whole video. One file.
- picture: a small dark JSON card, centred, six lines of real scene JSON
- object: the card sits alone in a quiet field
- why: establish the object before it does anything

## Beat 2: The file opens (3.5s-7s)
- onscreen: Every frame it names, | rendered the same way twice.
- narration: Change one number in here and the whole film re-cuts itself.
- picture: the card grows from one line to the whole file
- object: the card widens; the copy stays put
- why: the claim, made while the object demonstrates it

## Beat 3: The output (7s-11s)
- onscreen: Six frames. One source.
- narration: What comes out is not a preview. It is the film.
- picture: the card becomes the first tile of a grid of real rendered frames
- object: the card is now a cell among its own output
- why: show the product of the claim, not a restatement of it

## Beat 4: One video (11s-15s)
- onscreen: One video.
- narration: No timeline. No re-export. Just the file.
- picture: the grid collapses to a single hero frame with a ribbon orbiting it
- object: the card hands over to the frame it rendered
- why: the payoff lands on the thing the file made, not on the file
