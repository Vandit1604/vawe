# VOCABULARY: plain words the engine accepts

> GENERATED by `scripts/site/vocab-catalog.mjs` (`make vocab`) from `core/vocab.js`. Do not edit.

Every word below is accepted **in the slot the concrete value is accepted**, so reaching for the
right curve costs the same keystrokes as reaching for the wrong one. That is the whole point: a
word list you have to look up is a document, and a document only works on the author who already
stopped to read it.

A word is an ALIAS, never a new capability. The right column is what the engine actually runs, and
naming it directly still works and still renders identically. An **unknown word throws**, with the
near misses named. It is never quietly swapped for a default.

## Feel  `[ease]`

Any `ease` / `easing` / `settleEase` the ENGINE drives: a `motion` key, a `count`, a camera leg, `varsEase`. Not `parts[].ease` or `morph.ease`. Those go to GSAP and take GSAP names.

| word | resolves to | when |
|---|---|---|
| `snappy` | `"easeOutQuart"` | the house default for a decisive reveal. Arrives and stops, no wobble. |
| `smooth` | `"easeInOutCubic"` | the layer is travelling THROUGH the frame rather than arriving in it. |
| `soft` | `"settle"` | type, and anything that must stay readable the instant it lands. |
| `sharp` | `"easeOutExpo"` | a reveal that should read as a cut rather than a move. |
| `gentle` | `"easeInOutSine"` | idle drift, a held backdrop, anything the eye is not meant to follow. |
| `heavy` | `"easeInOutQuint"` | something large. The long ramp at both ends is what reads as mass. |
| `pop` | `"easeOutBack"` | a small element announcing itself: a chip, a badge, a tick. |
| `bouncy` | `"spring-bouncy"` | playful and loud. Wrong for a headline, right for a mascot. |
| `elastic` | `"easeOutElastic"` | the loudest curve here. Once per film, on the beat that can carry it. |
| `stiff` | `"spring-stiff"` | spring feel with the overshoot damped out. Premium, not toy. |
| `mechanical` | `"linear"` | a machine: a ticker, a conveyor, a progress bar that must not ease. |

## Duration  `[enterDur · exitDur · duration · transition.dur]`

The layer timing slots. A junction (`cuts[].dur`, `seams[].dur`, `stings[].dur`) still takes a number: the schema range-checks those, and a word would slip past the range unread.

| word | resolves to | when |
|---|---|---|
| `instant` | `0.08`s | a state change, not a move. Under the threshold where the eye reads travel. |
| `fast` | `0.18`s | quick, but still legibly a move. |
| `medium` | `0.3`s | the engine's own default entrance. Reach past it on purpose, not by omission. |
| `slow` | `0.6`s | the eye follows the whole path. For a subject, not for furniture. |
| `luxurious` | `1.2`s | a held gesture. One per film. |

## Camera  `[cameraMove.move]`

The shot, described. `{ "cameraMove": { "move": "pull back", "dur": 3 } }`. The move's own params are unchanged and still come from `core/camera-moves.js`.

| word | resolves to | when |
|---|---|---|
| `push in` | `"slowPush"` | the frame stays alive under a held beat. |
| `slow push-in` | `"slowPush"` | the same shot, spelled the way a director says it. |
| `pull back` | `"workspaceZoomOut"` | a detail turns out to be part of something larger. |
| `zoom out` | `"workspaceZoomOut"` | the same shot, spelled the way a director says it. |
| `dive` | `"diveIn"` | go INTO a point: a screen, a card, a marker on a map. |
| `follow` | `"panFollow"` | content grows downward (a terminal, a feed) and the camera tracks it. |
| `sweep` | `"truck"` | plain lateral travel. Reads as tracking, never as a lurch. |
| `tour` | `"travel"` | fly station to station across a canvas bigger than the frame. The camera IS the cut. |
| `pan stations` | `"travel"` | the same travel, spelled the way a board describes it. |
| `circle` | `"orbit"` | a gentle 3D swing around the frame. |
| `ui focus zoom` | `"diveIn"` | go into one control of a captured interface, not the whole screen. |
| `punch in` | `"punchIn"` | a hard, short push on a beat. The camera reacting, not travelling. |
| `shake` | `"cameraShake"` | an impact. One hit, on the frame that takes it, never as texture. |
| `drift hold` | `"driftHold"` | a held shot that must stay alive. The smallest move the eye still reads. |
