# Route: explainer

- **Input:** a topic, article, or a set of facts/numbers, with no real product or site to capture.
  Visuals are invented, not captured.
- **Output:** a film that explains one topic and ends on its most counterintuitive fact. Sweet spot
  15-30s. Held pace band (6s+ per idea), never showreel pace.
- **Trigger:** "explain how X works", "make a video about this topic/data", a data-driven or
  educational brief with no brand site named. If a real site or product sits behind the data, prefer
  `launch-video.md` instead.

## Intake (ask before authoring)

- **DATA**: where the facts come from (a URL, a file, or pasted numbers). Numbers must be real and
  accurate; use `count` layer compaction and unit suffixes, never invented figures.
- **PAYOFF**: the single shocker fact, ordered last (hook -> suspense -> payoff, never spoiled early).
- **FEELING**: one style reference, since there is no site to anchor taste. Manufacture a taste anchor
  by hand (`vawe-video-planning`'s non-site path) rather than defaulting to a generic look.
- **AUDIENCE**: who watches, since it decides vocabulary and pace.

## Blueprint family + docs

- Load skill `vawe-video-planning`, non-site branch, then follow
  `docs/CRAFT/AUTHORING-WALKTHROUGH.md` end to end (its worked example is exactly this deliverable: a
  20s explainer on password cracking).
- `STORY.md` for the spine and the held pace band; `SHOW-DONT-TELL.md` so a claim renders as a real
  graphic, not only type.
- Blueprints: `statReveal` for the payoff, `chipGrid`/`cardCascade` for supporting points.
