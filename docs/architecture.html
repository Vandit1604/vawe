Vawe · engine map

One JSON becomes one video, and the same JSON always becomes the same video.

Everything below follows from that second clause. It is not a nice property, it is the load-bearing invariant: it is what lets frames be captured out of order across parallel browser tabs, and it is what every gate is ultimately protecting.

01 · The invariant

Read this first; the rest of the architecture is downstream of it.

renderFrame(n) is pure in n. Ask for frame 400 and you get identical bytes whether it is the first frame rendered or the last, whether frame 399 was ever rendered at all.

That is why the Go side can open several Chrome tabs and have each seek to a different part of the timeline simultaneously. Without purity, sharded capture would produce a video whose content depended on scheduling, which is another way of saying it would be broken and would look fine most of the time.

What it forbids. No accumulating state, no Math.random(), no wall-clock reads, no animation that advances by being ticked. Everything is a closed-form function of the frame. GSAP is vendored and used as a tween engine, but its ticker is stopped, the engine seeks its global timeline to t each frame rather than letting it run.

Guarded by make probe (render-order DOM purity, per scene), make canvas-purity (shader and canvas pixels), and make snap-all (a DOM signature diffed against a baseline across every shipped scene).

02 · One render, end to end

What actually happens when you run make video D=formats/scene/x.json.

your file formats/scene/<name>.json Self-describing. Declares module, theme, aspect, duration, layers, backgrounds, audio.
│
Go · cmd/render parse flags, resolve scene, plan the shard --workers, --fps, --draft, --alpha, --ss. Capped at 4 workers, for a measured reason.
│
Go · internal/scene chromedp drives N headless Chrome tabs Each tab loads scene.html, waits for __engineReady, then seeks renderFrame(n) and screenshots. Correct only because of the invariant.
│
browser scene.html + core/* build the frame Layers positioned, motion tracks evaluated, clips driven, transitions composited. The DOM at frame n is the picture.
│
Go · internal/encode ffmpeg: frame sequence → H.264 (+ optional film grain) Supersampled captures resolve here via a box filter.
│
Go · internal/audio PCM mixer: music bed + named sfx cues + VO ducking + limiter Silent by default. Audio is opt-in per scene.
│
out/ <name>.mp4 Muxed, loudness-normalised at the mux step.

Inside the browser half

ModuleResponsibility
core/motion/motion.jsBoot, the motion primitives (interpolate, spring, rise, fade, slide, wipe), easings, seeded randomness, text measurement, the theme system. All pure in n.
core/timeline/sequence.jsTimeline evaluators. motionAt() turns a layer's keyframe track into {dx, dy, scale, rot, opacity, blur, w, h, track}; cameraAt() does the same for the camera, including its 3D tilt.
core/timeline/clips.jsReads data-start/-duration/-track/-anim/-out off the DOM and drives timed multi-layer clips with enter/exit and z-order. Also the seek interface that drives paused WAAPI and GSAP.
core/layers/*One file per layer type. Each exports build() (once) and optionally frame() (per frame).
core/preload.jsThe one async phase, before the virtual clock starts. Images, fonts, components, GSAP, shaders. After it, every lookup is a static table, so purity holds.
core/layout/safe.jsCanvas dimensions and the safe box. Crucially, the safe box depends on destination. A 9:16 web hero and a 9:16 reel are the same shape with different chrome.
core/validate/validate.mjsSchema + theme validation. Runs in boot() before the first frame, so a bad scene fails fast rather than rendering wrong.

04 · Layer vocabulary

Around twenty primitives. A scene is a list of these plus timing; there are no templates and no per-topic code.

GroupTypesNotes
Contenttext image count svg html text carries the kinetic system (split by char/word/line, per-unit presets). html is raw authored markup, sanitised, static.
Surfacesrect group board doc component component is a captured real UI fragment. The highest-fidelity source available.
Light & FXglow beam paint shader raymarch three Shader-backed types are guarded separately by make canvas-purity.
Motionclip lottie cursor composition clip plays video as a preloaded PNG sequence. No <video>, because a video element cannot be seeked deterministically.

Above the primitives sit blocks (build-time sugar: a type:"block" layer expands into real layers at LOAD time, core/expand.js, no separate step) and blueprints (whole pre-directed beats, same mechanism). Both exist so that good motion is the default rather than something you re-derive from a blank file.

Each stage exists because it catches something the next one cannot. The animatic overrules the script's estimate; the style frames catch what the gates cannot see; the judge sheet catches what no static check can. A green ladder is necessary and not sufficient.

06 · The gate ladder

Forty-nine gate scripts. Eleven of them run as one command before every render.

Two gates run after the render because they need real pixels: make seam-check pulls the frames straddling every transition and flags luminance flashes, and make audit checks overlap, clipping, safe zones and contrast.

The gates are themselves tested. gate-mutation deliberately breaks 119 scenes and asserts each gate fires, and stays quiet when the scene is correct. A gate that cannot fail is decoration.

07 · Where render time goes

The cost model, measured rather than assumed.

Render time is roughly frames × capture pixels. Painting the frame is a rounding error: under one percent. Essentially all of it is getting pixels out of the browser and through the encoder.

KnobEffect
--draftSkips film grain. Fast preview.
--ssSupersample factor. Costs quadratically; resolves via a box filter at encode.
--workersParallel tabs. Capped at 4.
The worker cap is not arbitrary and not tuning. At 8 workers the renderer produced 8–11 corrupted frames per run, a different set each run; at 4, zero. Compositor determinism flags and a doubled settle wait did not fix it. If you raise it, that is the failure mode to watch for, and it will not be reproducible.

A 15-second 1080p film currently renders in roughly 30 seconds wall-clock on this machine.

08 · Open seams

The honest list: known-weak places, so you can push where it will actually move.

silent

The unknown-prop check is type-agnostic

The validator tests layer keys against one flat list of every prop in the schema. So a prop that is real on one layer type passes silently on a type that ignores it, fill on a rect did exactly this. The fix needs per-type prop lists in the schema. This is the single most likely source of the next silent bug.

measurement

Gates keep measuring the wrong unit

Three of the last four framework findings were not wrong rules but wrong measurements: a rotating layer measured by its empty bounding box, kinetic typography counted as an echo, a label on a card counted as a collision. The tell is always the same, satisfying the gate requires making the film worse.

missing

Three primitives that do not exist

Per-layer 3D tilt, masking type against a prop, and drop shadows keyed to a light direction. A spike has confirmed the 3D construction works and that the camera must sit on the layers' direct parent; the other two are unstarted. There is also no video layer.

debt

The library is more typographic than it should be

When the show-don't-tell gate landed, 52 of 93 scenes carried no large picture at all. Eighteen short films waive the continuity rule. Neither was a decision; both are debt, and copying those scenes propagates it.

cheap

Render knobs whose reasoning is stale

The settle wait is now about 11% of a render, up from under 1%, because everything around it got faster. The 4-worker cap was measured under PNG pressure that no longer exists. Both are worth re-measuring, and neither has been.
