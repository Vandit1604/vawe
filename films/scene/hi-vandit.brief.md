# Brief: hi-vandit

No brand site: this is a personal title card, not a product. The five lines, as given by the user,
plus the two the author always fills.

```
SUBJECT   a personal intro card: "Hi im Vandit"
DATA      none needed: no numbers, no claims, just a name
PAYOFF    the word "Hi" turns into a waving hand
AUDIENCE  people meeting Vandit through his work (a portfolio, a repo, a deck)
FEELING   fast, light, confident. Not corporate.
```

```
SPECTACLE the one beat, the mark layer: "Hi" resample-morphs (core/layers/path-morph.js) into a
          waving-hand outline on a hand-keyed scale/rotate track, landing the wave with a small
          settle. The one loud moment in a film that has only one beat.
NOT       no corporate blue, no gradient hero, no stock hand photo or emoji hand, no slogan under
          the name, no second idea competing with the morph, no camera move standing in for content
          motion (AGENTS.md: a moving camera over static type reads as a slideshow with a wobble)
```

## The four things a brand site would have given, manufactured by hand

1. **Taste anchor**: no reference profile borrowed; this is a sting (`vawe-type-sting`), so the taste
   anchor is the type's own doctrine: one move, the mark, true black, kinetic register, held long
   enough to register.
2. **Real assets**: none captured. The "Hi" letterform and the waving-hand outline are both authored
   as plain SVG path data by hand for this film (no downloaded icon, no stock asset).
3. **Story spine**: none needed at 6s. A sting has no hook/build/payoff chain, one continuous object
   (the mark) unformed to formed, held.
4. **Real copy**: "Hi im Vandit" is the only on-screen text, exactly as the user wrote it. No invented
   claim, no number, no tagline.
