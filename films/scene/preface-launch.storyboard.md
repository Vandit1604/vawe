This video tells a developer that a file they write once is read by every agent they open.

## Beat 1: Hook (0s-5.2s)
- type: hook
- shot: wide, one line across the top, three chat cards scattered below it
- camera: hold
- picture: three hairline cards, each with an agent logo, each typing the same sentence at a different moment
- onscreen: "Every agent starts from zero." / "again, here is who I am" (x3)
- mechanism: the cards enter from three directions while the same line types itself out in each
- becomes: three separate tools become one repeated chore
- layout: the headline in the upper fifth, the three cards spread across the middle and lower thirds
- style: dead flat paper, the world before the file exists
- rest: nothing moves but the typing
- why: name the pain in one frame and let the repetition do the arguing
- duration: 5.2s
- transition_in: open
- backdrop: plain
