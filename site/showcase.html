What one JSON can render.

Every clip below is a single self-describing scene, rendered deterministically, scored automatically. No timeline, no editor.

01 / kinetic type

Type that moves like it reads.

Split by word or character, each line enters on its own preset, rise to decode to a focus-and-hold. The motion is part of the meaning.

preset: up · decode · gradient
02 / transitions

Cuts with intent.

Whip, punch, spin, zoom. One cut family per film, chosen by the motion director, each covered by a whoosh from the sound library.

cut: whip · punch · spin · zoom
03 / shader stings

GPU stings between beats.

Flash, glitch, scan, ripple. Real fragment shaders keyed on (progress, seed) only, so they are seek-safe and byte-reproducible.

sting: flash · glitch · scan · ripple
04 / data story

Charts that draw themselves.

A line chart draws on, a number counts up, KPIs land. The easing is the story. All from a data array in the scene JSON.

block: lineChart · statBig · kpiRow
05 / product UI

Product demos, rebuilt.

A dashboard inside a browser frame, a cursor that glides in and clicks, and the click has a consequence: a toast confirms the render.

block: browserFrame · cursor · toast

06 / any aspect

One scene, every ratio.

Relative coordinates resolve per aspect: pin, a 12-column grid, optical centering. Render 16:9, 9:16, and 1:1 from the same source, in one pass.
