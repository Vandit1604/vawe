# Vawe
> Open-source HTML to video framework for programmatic video and motion graphics as code. Vawe renders a deterministic mp4 from one HTML page, so you or an AI coding agent can write a film the way you write anything else, and re-render it the day the numbers change. A free alternative to Remotion, HyperFrames and Motion Canvas.

A Vawe film is one HTML page (CSS, Web Animations, SVG, canvas or three.js). The renderer seeks it frame by frame under a virtual clock and encodes an mp4. Source and the page contract: https://github.com/Vandit1604/vawe (AGENTS.md).

## Install and use (for agents)
- Full guide as one Markdown file: https://vawe.dev/ai-agents.md. Everything in one text file: https://vawe.dev/llms-full.txt.
- Install from source (no npm package, no hosted API, no account): `git clone https://github.com/Vandit1604/vawe.git && cd vawe && npm install && bin/vawe doctor`.
- Make a film: `bin/vawe new hello --request "<the ask>"`, then `bin/vawe dev films/hello/page.html` (draft), `bin/vawe critique films/hello/page.html` (in a fresh session), `bin/vawe ship films/hello/page.html` (final mp4 in out/).
- The page contract: one `films/<name>/page.html`, `<meta name="duration" content="seconds">`, time is the seek (CSS keyframes, Web Animations or `window.seek(t)`), no timers or unseeded random, relative assets, `<audio>` tags for sound. Read AGENTS.md in the repo first.

## Site
- [Home](https://vawe.dev/): Write a web page, get a film. Video component clips rendered by vawe, how a page becomes a film, and questions.
- [features](https://vawe.dev/features): The decisions the engine makes for you: a virtual clock that refuses wall time, motion blur that follows the motion, and a loop that judges a film in a fresh session.
- [video-components](https://vawe.dev/video-components): Proven motion video components, each a short clip and one markdown file an agent copies. Every video component file is listed under Video components below.
- [inspiration](https://vawe.dev/inspiration): Motion videos made with Claude and other AI, from posts on X. Each one is listed under Inspiration below.
- [resources](https://vawe.dev/resources): Every vawe resource in one list: easing curves, the video components library, the plain files for agents, the five agent skills, guides, comparisons and the project pages.
- [about](https://vawe.dev/about): What vawe is, why a film is one HTML page, how it is built (Apache-2.0, public since 2026-09-16), its five rules, who makes it and how to help.
- [determinism](https://vawe.dev/determinism): A page seeked, never played: the same page produces the same frames on every render, in any order. How Vawe makes that true and how it checks it.
- [ai-agents](https://vawe.dev/ai-agents): An agent writes the film as one HTML page, one command renders and checks it, and a fresh session judges the result.
- [remotion-alternatives](https://vawe.dev/remotion-alternatives): "Remotion alternative" returns two different products: a hosted JSON video API, or a self-hosted rendering engine. What Remotion's own license requires, what Vawe and HyperFrames give away free, and where a hosted API fits instead. Read 2026-09-19.
- [when-determinism-matters](https://vawe.dev/when-determinism-matters): Byte-identical rendering is a real property, not a universal one. When it decides which engine to pick, and when a human editing a timeline by eye makes it beside the point.
- [hyperframes-alternatives](https://vawe.dev/hyperframes-alternatives): HyperFrames is HeyGen's self-hosted, Apache-2.0, agent-facing rendering engine, the closest peer Vawe has. Both compose from HTML, timed and made deterministic in different ways. Read 2026-09-19.
- [launch-video](https://vawe.dev/launch-video): How Vawe builds a product launch video: real captured UI, not invented mockups, one message per beat, from the site's own palette and type.

## Video components
Each video component is one markdown file an agent copies: when to use it, the CSS and WAAPI snippet, the notes and the sound cue. The gallery with clips is https://vawe.dev/video-components.
To filter: fetch https://vawe.dev/moves/index.json. Top-level groups, looks and jobs list the ids. Each video component has group, look, jobs, use (the when line), clip, md and duration.
A human link filters the same way: https://vawe.dev/video-components?group=end-a-film&look=paper&q=wipe (group, look and job take comma lists: OR within one, AND across).
