Most people never hand-write a scene file. They describe the film and an agent composes the JSON,
then iterates on the render. `AGENTS.md` at the repo root is the brief the agent reads before it
writes anything, so it already knows the house rules, the vocabulary, and the quality gates.

## The checklist: five lines

Any line may be missing; the agent asks if a missing one would change the film (`make quiz`, or
`vawe-video-planning`'s Step 1). One good and one weak version of each:

| Line | Weak | Good |
|---|---|---|
| SUBJECT | "a video about our app" | "our launch, the one-click deploy step" |
| DATA | (missing) | a URL, a file, or "here are the numbers" |
| PAYOFF | "it's great" | "the same input always renders the same bytes" |
| AUDIENCE | "everyone" | "developers, X and LinkedIn, 16:9 and 9:16" |
| FEELING | "modern" | "dry and technical, like a good changelog" |

<Callout type="warn">
If you find yourself naming a colour, an easing, or a layer type, stop. That is the agent's job.
Reaching for engine vocabulary means the brief above is thin, and the fix is a sharper PAYOFF or
FEELING, not a hex code.
</Callout>

Two more lines the agent fills itself, not you: `SPECTACLE` (the one exaggerated moment, named) and
`NOT` (what the film explicitly will not do). Both are locked into the plan before any JSON is
written.

## Inputs that raise quality

- **A real product URL, crawled, not invented.** `make sections` pulls the site's own colours, fonts,
  and favicon; a launch video must crawl every page and use captured UI, never a guessed one.
- **A reference film or site.** `make study REF=` measures it (shot timing, seam gaps, axis, ground
  colour); `make ideate REF=` then builds the film's structure from those real numbers, not a guess.
- **Real data.** Numbers, copy, and figures must be true and looked up, never invented for effect.
- **The video type, if you know it.** Naming "launch video," "explainer," or "a short sting" saves a
  routing step (`engine-doctrine/CRAFT/ROUTING.md`); otherwise the agent infers it from the brief.

## Words that work

The engine resolves plain words to real values in the slot each belongs to. An unknown word errors,
naming the near misses, instead of silently defaulting.

| Class | Example words | Resolves to |
|---|---|---|
| Feel | `snappy`, `soft`, `sharp`, `bouncy` | an easing curve |
| Duration | `instant`, `fast`, `medium`, `slow` | a number of seconds |
| Camera | `push in`, `pull back`, `dive`, `sweep` | a named camera move |
| Comparative | `faster`, `slower` | one step from the current value |

Full generated tables: `engine-doctrine/CRAFT/VOCABULARY.md` and, per primitive,
`engine-doctrine/CRAFT/PRIMITIVES-VOCABULARY.md` (both regenerate with `make vocab`).

## Three worked prompts

**Launch video**

```
SUBJECT   our launch, reflecting the real product UI
DATA      https://example.com  (crawl it, not just the homepage)
PAYOFF    it ships in one click
AUDIENCE  X and LinkedIn, 16:9 and 9:16
FEELING   like the site itself, no louder
```
Next: `make sections` + `make palette`, then `make ideate`, `make scaffold TYPE=launch`.

**Explainer**

```
SUBJECT   why deterministic rendering matters for CI
DATA      the render pipeline always produces the same bytes for the same input
PAYOFF    same input, same output, every time
AUDIENCE  developers, landing page, muted autoplay
FEELING   dry and technical, like a good changelog
```
Next: `make ideate NAME=determinism`, `make scaffold TYPE=explainer`.

**Short sting**

```
SUBJECT   a 6s logo reveal for Loom, dev tool
PAYOFF    the mark lands hard, nothing else on screen
AUDIENCE  a pre-roll bumper, any platform
FEELING   one word landing hard, dark ground
```
Next: `make scaffold TYPE=sting DUR=6`.

Every path then runs the same ladder: `make author-check` → `beats`/`reveal` → `make video` →
`make judge` → `make ledger`.

## What to avoid

- **Don't ask for a template.** There are none: every film composes from
  `engine-doctrine/PRIMITIVES.md`; a scaffold is a shell, not a reusable layout.
- **No em-dashes in on-screen copy.** The validator rejects them; use a comma, a period, or a middot.
- **Don't invent UI.** A screen, logo, or photo the plan names must trace to a real capture
  (`make capture`/`make assets`); a fragment with no real source is blocked before it ships.
