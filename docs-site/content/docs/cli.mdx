One command runs everything: `bin/vawe`. `bin/vawe --help` lists the core verbs and `bin/vawe --help --all` lists every verb. `bin/vawe <verb> --help` lists the flags. A wrong flag exits 2 and prints the valid ones.

The core verbs, the loop:

| Verb | What it does |
|---|---|
| `new` | start a film: `films/<name>/page.html` and `brief.md` |
| `refs` | list the reference films, print the settled frame of every shot, add a film |
| `see` | read a film, page or reference completely: shots, motion, light, type, sound. `--vs <ref>` adds deltas and advice. `--spec` measures a reference into `SPEC.md` and `spec.json` |
| `frames` | one still per world and a contact sheet. `--looks` shows every lens look |
| `storyboard` | one HTML board with a card per world. `--text` prints worlds, rhythm and cues as text |
| `dev` | draft render: half size, 30 fps, audio mixed (a `--from/--to` window is silent), plus a key-frame sheet PNG |
| `strip` | the frames through one moment or every cut, with motion numbers. `--onion` and `--velocity` show one move |
| `sheet` | a labelled contact sheet of seconds. `--ref <mp4>` puts the reference beside your frames |
| `still` | one exact full-size frame as a PNG |
| `wait` | wait for a running render and print its result |
| `sound` | synth voices, the beat grid and hits of a track, the cues of a page. `--sfx` imports an effect, `--lab` listens |
| `critique` | phone sheet, strip, loop seam, measured deltas and `page-check` |
| `approve` | the owner signs off the draft. `ship` needs it |
| `ship` | final render: 60 fps, motion blur, audio mixed, then a final check and a fresh judge. Runs in the background |
| `check` | run one gate or report by name (`review`, `coverage` and `links` among them). Bare `check` lists them |

More verbs, shown by `--help --all`:

| Verb | What it does |
|---|---|
| `zoom` | one region of a frame enlarged with no smoothing, beside a second film |
| `shot` | screenshots of a site route, a url or an html page at several widths |
| `judge` | prepare key frames and the rubric for a fresh session to score |
| `fonts` | the free font faces |
| `palette` | one OKLCH brand seed |
| `studio` | live scrubbable preview. It edits the page literals in place |

Maintainer verbs: `e2e`, `test`, `land`, `claim`, `doctor`, `runs`, `moves`.

## The flags you use most

```bash
bin/vawe new my-film --from prompts/story-explainer.md --length 30 --aspect 16:9 --title "..."
bin/vawe dev films/my-film/page.html --from 2 --to 6 --aspect 9:16 --audio
bin/vawe ship films/my-film/page.html --aspect all
bin/vawe ship --status --wait
bin/vawe sheet films/my-film/page.html --at 2.5,3.1,4
bin/vawe studio films/my-film/page.html --port 8800
```

- `new --ref <mp4>` recreates a reference. It writes `films/recreations/<name>` with `SPEC.md`.
- `dev --out <path>` sets the output file. The default is `out/<name>-draft.mp4`.
- `ship --out <path>` sets the output file. The default is `out/<name>.mp4`. It does not combine with `--aspect all`.
- `ship --wait` blocks until the render ends. `ship --status` prints the progress or the result, and with `--wait` it waits at most 100 s.
- `critique --ref <mp4>` measures against a reference. With `--final`, a pass unlocks `ship`.
- `judge --fresh` scores now with a separate headless session. It advises and never blocks.

## The loop, end to end

```bash
bin/vawe new my-film --from prompts/<template>.md   # brief and starter page
bin/vawe dev films/my-film/page.html                # draft
bin/vawe critique films/my-film/page.html           # in a fresh session
bin/vawe dev films/my-film/page.html --from 2 --to 4  # fix only the named seconds
bin/vawe ship films/my-film/page.html               # final
```

See [Quality gates](/docs/quality-gates) for `check`, and [Reading your film](/docs/reading-your-film) for the views.
