Vawe turns one HTML page into one film. You write the page in what you already know: HTML, CSS, Web Animations, SVG, canvas, three.js. There is no private format to learn. If something you would naturally write fails, that is a framework bug.

The renderer does not play the page. It seeks the page to a time, takes a picture, and moves to the next time. Then it mixes the audio offline and writes an mp4.

```bash
bin/vawe new hello        # writes films/hello/page.html and brief.md
bin/vawe dev films/hello/page.html
# draft: out/hello-draft.mp4
```

## Two ideas

**A film is a page.** It is `films/<name>/page.html` plus its own `assets/` folder. A `<meta name="duration">` sets the length. Read [The page](/docs/the-page) for the whole contract.

**Time is the seek, never the clock.** Every frame is a function of the time `t`. A virtual clock owns `Date`, `requestAnimationFrame`, timers and `Math.random`, so the same page gives the same frames on every run. Read [Determinism](/docs/determinism).

## The loop

Brief or reference, then stills, then a draft, then a critique in a fresh session, then a fix of only the seconds the critique names, then the final.
