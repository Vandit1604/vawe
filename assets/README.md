# assets/

Standing assets a film loads at render time: fonts, icons, flags, cutouts, geo and globe data, music,
sound effects, brand kits (`brands/`) and vendored third-party files (`vendor/`).

Read by: the renderer, and the generators under `generators/` that write files here. Regenerate a
baked asset by re-running its generator; do not hand-edit it.

Licences: `assets/README-LICENCE.md` says which sources are redistributable and which are not. The
Resource Boy gradient and ransom packs must never leave this machine.
