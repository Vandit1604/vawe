# assets/: what stays in git, and the licence of every set

Read by the renderer and by the generators under `generators/` that write files here. Regenerate a baked asset by re-running its generator; do not hand-edit it. The mixer builds sound cues from code, not from `sfx/`. Put a brand's marks in `assets/brands/<name>/` (or `assets/icons/`); a page loads them by path. Only `brands/*/house-style.md` is tracked.

Tracked in git (we may share these):

- `fonts/3d/*.typeface.json`: outlines baked by `generators/fonts` from Anybody and Fraunces, both SIL OFL 1.1.
- `geo/`, `globe/`: Natural Earth 110m admin-0 (public domain) and us-atlas states (US Census TIGER, public domain).
- `flags/`: flagcdn.com, public domain per the site's own terms.
- `icons/ui/`: Lucide static v0.460.0, ISC. `icons/markdown*.svg`: Markdown mark, CC0 (Simple Icons).
- `icons/vawe-wave.svg`, `icons/ledgerline-mark.svg`, `lottie/`: made in this repo, Apache-2.0.
- `vendor/`: see `vendor/README.md`, one licence per file.
- `brands/*/house-style.md`: our notes, Apache-2.0.

Local only, gitignored:

- `sfx/*.wav`: generated by `node generators/media/audio-bake.mjs` from `core/audio/kit.mjs`. No licence, no download. The mixer does not read them.
- `music/*.wav`: Mixkit free tier (commercial use, no attribution; redistributing the files alone is forbidden), so never committed. Provenance: `music/credits.json`.
- `fonts/*.woff2`: fetched by `node generators/media/fonts.mjs` from Fontsource (OFL 1.1 or Apache). `fonts/local/` holds paid faces (Sohne) that are never shared.
- `brands/`, third-party logos in `icons/`: trademarks. The file licence (often CC0) does not cover the mark.
- `gradients/`, `ransom/`, `ransom-src/`: Resource Boy packs, no redistribution.
- `vawe-flow-2/`: one film's stills and renders.

A new asset set needs a line here, with its licence, before it is committed.
