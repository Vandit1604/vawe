---
id: show-real-thing
step: concept
principle: Each beat shows a real artifact working: the real UI for a real product, the brand's own mark and world for an invented one. A word in a box is not a beat.
limit: none
range: a capture, a drawn real artifact or a live demo in every beat that makes a claim
break-when: a film whose whole idea is type on a field, decided on purpose and defended in the brief
instead: render a mini-scene so the viewer watches the thing work (a value changes and the output updates; the real word cycles through colours). If a cursor clicks, the next frames show what the click did. For a real product, capture the real UI. For an invented product the brief asks you to invent the UI: design it as a real interface (one UI skill, real-looking data, controls that do something), then place it in the frame. Only fake chrome with no function, or a placeholder label, is the pitfall.
check: judge
judge: Name the artifact that earns each beat. Which beat holds only a word in a box, chrome with no function or a click with no result?
prevents: feedback: "it shows so little" (launch film). About 4 in 10 shipped scenes carried no picture of any size and the median film gave about 5 percent of its layers to picture. doc TASTE.md: "produced, not generated".
status: active
scored: yes
numbers: {}
digest: Show real things working, not slogans in boxes; an invented product gets a UI designed as a real interface, never functionless chrome.
craft: show-dont-tell
---

## Example

Right: "any colour" is the real word cycling through colours. Wrong: the text "any colour" in a pill.
